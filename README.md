**CoreMVC** — это легковесный самописный PHP-фреймворк, созданные в образовательных целях. 

## 🎯 Цель проекта
Проект разрабатывался с нуля **без использования сторонних библиотек и готовых фреймворков (Laravel, Symfony и т.д.)**. 
Главная задача этого проекта — глубокое понимание того, как работают современные веб-фреймворки "под капотом", прежде чем переходить к промышленной разработке на Laravel. Имея опыт программирования на **C**, для меня было важно разобраться с маршрутизацией, управлением памятью, паттернами проектирования и архитектурой MVC на базовом уровне.


## ✨ Ключевые возможности (Features)

* **Архитектура MVC:** Строгое разделение логики (Model), представления (View) и контроллеров (Controller).
* **Самописный Routing (Маршрутизация):** Система роутинга для обработки HTTP-запросов и привязки их к нужным контроллерам.
* **CRUD операции:** Базовая реализация работы с базой данных (через PDO).
* **Админ-панель:** Интерфейс для управления контентом и настройками.
* **Система расширений и настроек:** Возможность гибко изменять конфигурацию проекта.
* **Однопоточный парсер:** Скрипт для сбора данных.

## 🛠 Технологический стек

* **Backend:** Чистый PHP (Vanilla PHP), ООП подход
* **Database:** MySQL (использование PDO для безопасных запросов)
* **Frontend:** HTML5, CSS3
* **Паттерны проектирования:** MVC, Singleton, Front Controller
